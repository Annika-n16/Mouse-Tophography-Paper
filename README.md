# Mouse-Tophography-Paper
This repo contains the python files and raw data files that are being used towards the publication of a paper outlining the difference in mouse behavior based on schedule type. 

## Running the notebook
1. Keep `IRTs_TRmodel1.mat` in the same folder as `TopographyTRModel (1).ipynb` (the notebook loads it by file name only).
2. Install the packages: `pip install -r requirements.txt`
3. Open the notebook in Jupyter and run all cells. Figures are saved to `figures/` (PNG and PDF) and the model statistics to `topography_gamma.csv` / `topography_params.csv`.
